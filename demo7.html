📜 Keyframe Syntax Structure

Compare percentage stops (0% - 100%) versus keyword stops (from / to).

/* Keyword Syntax (2 States) */ @keyframes simpleFade { from { opacity: 0.2; } to { opacity: 1.0; } } /* Percentage Syntax (Multi-stage) */ @keyframes slideAndRotate { 0% { transform: translateX(0px); } 50% { transform: translateX(250px); } 100% { transform: translateX(500px); } }

📚 CSS Animation Sub-Properties Summary Reference

animation-name: slideAndRotate; /* Binds the @keyframes rule name */ animation-duration: 3s; /* Time to complete 1 cycle (e.g. 3s, 500ms) */ animation-timing-function: ease-in-out; /* Acceleration curve (linear, ease, cubic-bezier, steps) */ animation-delay: 2s; /* Wait time before execution starts */ animation-iteration-count: infinite; /* Number of repeats (integer or 'infinite') */ animation-direction: alternate; /* Motion direction (normal, reverse, alternate, alternate-reverse) */ animation-fill-mode: forwards; /* Style applied before start / after end (none, forwards, backwards, both) */ animation-play-state: running; /* Controls runtime playback (running | paused) */ /* Shorthand Syntax Order: */ animation: slideAndRotate 3s ease-in-out 2s infinite alternate forwards;
