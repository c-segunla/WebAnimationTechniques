🏀 Element 2: Squash & Stretch Bounce

⚙️ CSS Keyframe Rules Breakdown

Keyframe animations transition an element smoothly through multiple intermediate keyframes (expressed in percentages 0% to 100%).

/* 1. Keyframes Definition */ @keyframes ballSquashBounce { 0% { transform: translateY(-160px) scaleY(1.05); } 50% { transform: translateY(0px) scaleY(0.65); } /* Squash */ 100% { transform: translateY(-160px) scaleY(1.05); } } /* 2. Applying Animation to Target Selector */ .bouncing-ball { animation-name: ballSquashBounce; animation-duration: 1.4s; animation-timing-function: cubic-bezier(...); animation-iteration-count: infinite; }
